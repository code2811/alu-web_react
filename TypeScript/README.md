# TypeScript

TypeScript project covering interfaces, classes, namespaces, ambient declarations, and nominal typing.

## Tasks

- **task_0** - Student interface and DOM table rendering
- **task_1** - Teacher interface, Directors, printTeacher function, StudentClass
- **task_2** - Advanced types, createEmployee, type predicates, string literal types
- **task_3** - Ambient namespaces and external library declarations
- **task_4** - Namespaces and declaration merging
- **task_5** - Brand convention and nominal typing

## Setup

```bash
cd task_0   # or task_1, task_2, task_3, task_5
npm install
npm run build
npm run start-dev
```

For task_4:
```bash
cd task_4
npm install
npm run build
```
