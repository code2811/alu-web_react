# ALU Web React

This workspace contains the ALU web development exercises. The root npm scripts run the first React component task:

```bash
npm install --prefix React_component/task_0/dashboard
npm start
npm run build
npm test
```

The dashboard source is in `React_component/task_0/dashboard`. The development server opens at `http://localhost:3000` unless another port is supplied:

```bash
PORT=3001 npm start
```

## Exercise folders

- `React_component` - React components and props
- `React_inline_styling` - React inline styling
- `react_intro` - React fundamentals
- `TypeScript` - TypeScript interfaces, classes, namespaces, and types
- `Webpack` - Webpack configuration and asset loading

To work on another exercise, change into that exercise's project folder and run its local npm scripts.
