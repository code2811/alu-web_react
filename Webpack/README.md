# Webpack

Webpack project covering basic setup, config files, CSS/image loaders, dev servers, modules, and tree shaking.

## Tasks

- **task_0** - Basic Webpack setup with jQuery, no config file
- **task_1** - Webpack config file, Lodash debounce, production build
- **task_2** - CSS and image loaders, optimized assets
- **task_3** - Dev server, multiple entry points, code splitting, plugins

## Setup

```bash
cd task_0   # or task_1, task_2, task_3
npm install
npm run build
```

For task_3 dev server:
```bash
cd task_3
npm install
npm run start-dev
```
